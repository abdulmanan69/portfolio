🐒 MonkeyGhost

Stealth autotyper userscript for Monkeytype.
Human-like speed, accuracy, jitter and mistakes — driven straight into the hidden input, no clicks or screen coordinates.

✨ Features
⌨️ Hidden-input engine Dispatches real keydown / input / keyup into Monkeytype's own field — no OS keystrokes, no pixel clicking.
🎯 Target WPM & accuracy Set any WPM and accuracy in the overlay; the engine matches it.
🧠 Human mistake engine Types wrong letters, pauses, then backspaces — like a real typist.
🌊 Gaussian jitter Randomized per-key timing so the rhythm never looks robotic.
🚀 Digraph bursting & ramp-up Speeds up on common pairs (the, er, on), starts slower, pauses on space.
🎛️ On-page UI Overlay panel in Monkeytype's own theme.
🖱️ Double-Shift trigger Start/stop with a quick double tap of Shift, or the button.

📦 Install

  1. Install the Tampermonkey browser extension.
  2. Open the Tampermonkey dashboard → Create a new script.
  3. Delete the template, paste the contents of monkeyghost.user.js, and Save (Ctrl+S).
  4. Go to monkeytype.com — the 🐒 MONKEYGHOST panel appears bottom-left.

▶️ Usage

  1. Set your target WPM and ACC in the panel.
  2. Start a typing test (click the words so the test is active).
  3. Press Shift twice quickly (or click Start) to begin.
  4. Press Shift twice again — or click Stop — to halt at any time.

⚙️ How it works

MonkeyGhost never simulates the operating-system keyboard. It:

  1. Scrapes the target text from #words .word > letter nodes.
  2. Writes each character straight into Monkeytype's hidden input, firing the exact keydown → input → keyup event sequence the site expects.
  3. Shapes the timing with Gaussian jitter, ramp-up, digraph bursts and space pauses, plus an occasional typo-and-backspace so the run reads as human.

⚠️ Disclaimer

For educational and personal experimentation only. Automating typing tests violates Monkeytype's rules and any submitted result will not be legitimate. Do not use it on leaderboards. You use this at your own risk.
