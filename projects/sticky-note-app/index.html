Sticky Notes App

A desktop-style sticky notes application built with HTML, CSS, and JavaScript that allows you to create, drag, edit, and organize virtual sticky notes on your screen.

Features

  • Realistic Sticky Notes: Visually resembles real sticky notes with paper bends, soft drop shadows, and textured look
  • Drag and Drop: Move notes anywhere on the screen with smooth animations
  • Editing: Type and edit content directly in each note
  • Persistent Storage: Notes are saved in local storage and maintain position after reopening
  • Multiple Colors: Choose from yellow, pink, green, and blue sticky notes
  • Minimal UI: Clean interface with just a "+" button to add new notes
  • Help System: Built-in help instructions accessible with the "i" button
  • Responsive Scrollbars: Transparent scrollbars appear when note content exceeds the note size

How to Use

  1. Click the "+" button to create a new sticky note
  2. Drag notes by their header to move them around the screen
  3. Type directly in notes to add content
  4. Notes are automatically saved and will persist after closing
  5. Click the "×" button on a note to delete it
  6. Click the "i" button for help and usage instructions
  7. Scrollbars appear when note content exceeds the note size

Technical Details

  • Single HTML file application with no external dependencies
  • Uses localStorage for persistent note storage
  • Responsive design that works on different screen sizes
  • Modern CSS features including gradients, shadows, and custom scrollbars

Browser Compatibility

Works in all modern browsers that support localStorage and modern CSS features (Chrome, Firefox, Edge, Safari).
