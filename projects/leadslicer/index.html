🎯 What It Does

LeadSlicer takes your large lead file and lets you:

  1. Upload — Drag & drop any .csv or .xlsx file
  2. Preview — See the first few rows, total row & column counts
  3. Configure headers — Use first row as header or auto-generate column names
  4. Select columns — Keep only the columns you need
  5. Filter & clean — Remove duplicates, empty rows, and rows with missing values
  6. Chunk — Split into smaller files of any size (100, 500, 1000+ rows)
  7. Download — Get individual files or everything as a ZIP

📅 Format Fidelity

A value comes out of LeadSlicer looking exactly like it went in. Spreadsheets store a date as a serial number (05/03/2026 is really 46086) and only show it as dd/mm/yyyy because of the cell's number format — so a naive reader hands you the raw serial and your dates turn into meaningless integers.

LeadSlicer avoids that on both ends:

  • On import, the workbook is read with cellDates, cellNF and cellText, and every cell is taken as its rendered text. A dd/mm/yyyy cell reads back as 05/03/2026, never 46086. Each column's number format is recorded.
  • On export, that format is reapplied. The date is written as a real date cell carrying dd/mm/yyyy, so Excel shows and sorts it exactly as before. Anything that cannot be parsed back with confidence stays as literal text rather than being guessed at.
  • CSV is passed through byte-for-byte — no re-interpretation, no locale surprises, UTF-8 BOM preserved so Excel opens it correctly.

The same applies to currency and number formats: 1,234.50 stays 1,234.50.

Source file 05/03/2026 1,234.50
Exported chunk 05/03/2026 1,234.50

🎨 Theming

Click the button in the top-right corner to open the theme picker:

  • Appearance — Light, Dark, or System (follows your OS and updates live)
  • Accent — Indigo, Violet, Emerald, Rose, Amber, or Cyan

Preferences persist in localStorage, sync across open tabs, and are applied before first paint so there is no flash of the wrong theme on load. Shift-click the button to cycle appearance without opening the panel.

📱 PWA

LeadSlicer is a fully installable Progressive Web App:

  • ✅ Works offline after first load
  • ✅ Install on Android, iOS, and Desktop
  • ✅ Cached with Service Worker
  • ✅ Splash screen & standalone mode

Install: Visit the site → click "Install" in browser address bar (or "Add to Home Screen" on mobile).

🔒 Privacy & Security

  • Zero data collection — No analytics, no tracking, no cookies (unless you add GA)
  • No server uploads — All processing happens in your browser via JavaScript
  • No external API calls — Fully self-contained
  • Security headers — CSP, HSTS, X-Frame-Options, X-Content-Type-Options
  • HTTPS enforced — via Cloudflare

Your data stays on your machine. Period.
