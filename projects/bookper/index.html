From the README

Double-entry bookkeeping for small businesses, Pakistan first. A desktop app: each company's books live in one SQLite file on the PC, so it works with no internet. Keyboard first — every screen can be driven without the mouse.

What's in it

  • Accounts — customers, suppliers and the full chart of accounts, with opening balances.
  • Vouchers — sales, purchases, credit and debit notes, estimates, purchase orders, receipts, payments, contra, journal, expense and income, with bill-wise settlement, other charges, discounts and sales tax.
  • Inventory — items, services, units of measure (including compound units), stock on hand and item history.
  • 30 reports — balance sheet, profit and loss, trial balance, ledgers, day book, registers, tax computation and register, outstanding payable/receivable, ageing, stock reports, ratio analysis and more, each exportable to a web page, Word, Excel or PDF.
  • Inventory valuation — FIFO, AVCO, weighted average, inward-quantity average and the older FIFO method, chosen in Settings and used by every report that values stock.
  • Settings — general settings, voucher series, warnings and restrictions, POS entry options and report settings.
  • Tools — export masters and transactions to Tally, cheque printing, item barcode labels (Code 128) and envelope printing.

Built with

.NET 10, Avalonia 12 (compiled bindings), CommunityToolkit.Mvvm, EF Core 10 on SQLite, SkiaSharp for printing, xUnit v3 with Avalonia headless tests.

Building and running

dotnet build Bookper.slnx -c Release
dotnet run --project src/Bookper.App

Tests:

dotnet test --solution Bookper.slnx -c Release
