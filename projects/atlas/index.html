Requirements

Tool Version
Docker Desktop / Engine 24+ (Compose v2)
Python 3.12 (installed automatically by uv)
uv 0.8+
Node.js 22 LTS (web app)
pnpm 10

First run

cp .env.example .env              # then set ATLAS_JWT_SECRET and ATLAS_SECRETS_ENCRYPTION_KEY
docker compose up -d postgres redis
cd services/api
uv sync
uv run alembic upgrade head
ATLAS_DEMO_PASSWORD='choose-one' uv run python -m app.seed   # optional synthetic demo data
uv run uvicorn app.main:app --reload --port 8080
  • API docs: http://localhost:8080/docs (Swagger) · http://localhost:8080/redoc
  • Health: http://localhost:8080/api/v1/health/ready
  • Worker: uv run arq app.workers.main.WorkerSettings
  • Self-hosted voice demo on another PC, fully offline, in one command (.\make.ps1 demo): docs/university-demo.md

Web app (second terminal):

cd apps/web
pnpm install
pnpm dev            # http://localhost:5173 (proxies /api to :8080)
pnpm gen:api        # regenerate src/types/api.d.ts after API changes

Windows: every command above works in PowerShell. Or use the task runner: .\make.ps1 infra, .\make.ps1 dev-api, .\make.ps1 check. On Linux/macOS: make infra, make dev-api, ….

Quality gates

cd services/api
uv run ruff check app tests && uv run ruff format --check app tests
uv run mypy app          # strict
uv run pytest -q         # needs the compose postgres + redis (uses db atlas_test, redis db 15)
uv run alembic check     # models and migrations in sync

On a slow PC, run the API tests on the Oracle server instead (one file or the whole suite; the first run installs the dependencies there):

bash infra/scripts/remote_api_tests.sh tests/test_campaigns.py

Safety defaults

Real phone calls are disabled unless ATLAS_LIVE_CALLS_ENABLED=true and the campaign is launched by a user holding campaigns:launch_live. Operators are responsible for call disclosure, recording consent, opt-out handling, and local calling regulations.
