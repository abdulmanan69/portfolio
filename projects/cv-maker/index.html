Features

  • 12 professional templates — Classic, Horizon, Minimal, Executive, Bold, Tech, Timeline, Swiss, Gradient, Compact, Paper, Onyx — covering ATS-friendly, sidebar, timeline, dark, serif and dense formats.
  • Live preview with real A4 / US Letter pages and smart pagination — content flows automatically across pages, and "Fit to 1/2/3 pages" auto-shrinks to hit a target.
  • Photo upload + editor — drag & drop an image, then pan, zoom, rotate, and tune brightness / contrast / saturation / grayscale / sepia; circle, rounded or square shape.
  • Drag & drop everything — reorder sections, entries, skills and links with smooth FLIP animations.
  • Customize everything — accent color (palette, hue/lightness sliders or hex), body and heading fonts, text size, line height, section spacing, margins, heading style, date format, photo settings.
  • QR code on your CV — generated 100% locally (no external service); link it to your website, GitHub, LinkedIn, email, phone or a scannable contact card; pick corner + size.
  • Realtime design — color, font and spacing changes render live while you drag.
  • PDF download plus print support (Ctrl+P → Save as PDF gives a vector-quality copy).
  • Custom UI everywhere — hand-built dropdowns, month/year picker, sliders, color picker and toggles; no native browser form popups.
  • Undo / redo (Ctrl+Z / Ctrl+Y), autosave to localStorage, JSON backup import/export, sample data, dark mode.
  • 10 section types: experience, education, skills, languages, projects, certifications, awards, interests, references and unlimited custom sections.

Run locally

Just open index.html in a browser — no build step, no dependencies.

Deploy to GitHub Pages

  1. Create a repository (e.g. cv-maker) and push these files to the main branch.
  2. Repository Settings → Pages → Source: select main branch, / (root).
  3. Your app is live at https://<username>.github.io/cv-maker/.

SEO (already set up)

The site ships with full search-engine + AI-search optimization: meta description and keywords, Open Graph / Twitter cards with a social preview image, JSON-LD structured data (WebApplication + FAQ + author), robots.txt, sitemap.xml, llms.txt for AI crawlers, a PWA manifest.webmanifest with icons, and crawler-readable static content in index.html. Everything is pre-configured for https://abdulmanan69.github.io/cv-maker/ — if your repository name is different, search-and-replace that URL in index.html, robots.txt and sitemap.xml once before deploying. After deploying, submit sitemap.xml in Google Search Console and Bing Webmaster Tools for fastest indexing.

Tech

Vanilla JavaScript, hand-written CSS, canvas-based image editing, custom pagination engine. PDF export uses html2canvas + jsPDF loaded on demand from a CDN (with a print fallback when offline).
