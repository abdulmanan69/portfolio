From the README

A modern, feature-rich callback reminder application built with HTML, CSS, and JavaScript. This web app helps you manage customer callbacks with notifications, reminders, and a sleek glass-morphism design.

🌟 Features

Core Functionality

  • Add and Manage Callbacks: Schedule callbacks with customer names and specific dates/times
  • Visual Status Indicators: Clear color-coded badges for pending, today, overdue, and completed callbacks
  • Search Functionality: Quickly find callbacks by customer name
  • Persistent Storage: All data saved in browser's localStorage

Notification System

  • Browser Notifications: Get notified when it's time for a callback
  • Custom Ringtone Alerts: Enable audio alerts with a custom notification sound
  • Smart Notification Handling: Each reminder only triggers once with a notified flag
  • Permission Management: Easy control over notification permissions

User Experience

  • Dark/Light Mode: Toggle between themes based on your preference
  • Responsive Design: Works on desktop, tablet, and mobile devices
  • Glass-Morphism UI: Modern frosted glass design with smooth animations

🚀 Getting Started

Prerequisites

  • A modern web browser (Chrome, Firefox, Safari, Edge)

Installation

  1. Clone the repository: 
    git clone https://github.com/yourusername/callback-tracker.git
  2. Navigate to the project directory: 
    cd callback-tracker
  3. Open index.html in your browser or serve it with any static file server

Usage

  1. Enter customer name and callback date/time
  2. Click "Add Callback" to schedule
  3. Enable notifications by clicking "Enable Notifications"
  4. Enable ringtone alerts by clicking "🔊 Enable Ringtone Alerts"
  5. Search for specific callbacks using the search bar
  6. Mark callbacks as done or delete them when completed

🎨 Design Features

Glass-Morphism UI

  • Frosted glass effect panels with backdrop blur
  • Smooth transitions and hover animations
  • Responsive layout that adapts to all screen sizes
  • Consistent design language across light and dark themes

Color Scheme

  • Primary Blue: #007bff (actions and highlights)
  • Success Green: #28a745 (completed items)
  • Danger Red: #dc3545 (delete actions and overdue items)
  • Dark Theme: #1e1e2f background with light text

🔧 Technical Implementation

Data Storage

  • Uses localStorage for persistent data storage
  • No backend required - fully client-side application
  • Data persists between browser sessions

Notification System

  • Browser Notification API for visual alerts
  • HTML5 Audio API for ringtone playback
  • 30-second interval checking for due callbacks
  • Notified flag prevents duplicate notifications

Responsive Design

  • Flexbox-based layout for adaptive sizing
  • Media queries for mobile optimization
  • Relative units for scalable elements

🌐 Browser Support

  • Chrome 70+
  • Firefox 65+
  • Safari 12+
  • Edge 79+

🎵 Audio Features

  • Custom notification sound (notification.mp3)
  • 5-second playback duration for alerts
  • Audio only plays when ringtone alerts are enabled
  • Graceful degradation if audio playback fails

🛠 Development

Local Development

To run locally:

# Using Python
python -m http.server 8000

# Using Node.js (if serve is installed)
npx serve -p 8000

Customization

  • Modify color scheme in the CSS :root variables
  • Replace notification.mp3 with your own sound
  • Adjust check interval in startNotificationChecker() function

🔒 Privacy

  • All data stored locally in your browser
  • No data is sent to any server
  • Notifications work entirely client-side
  • No tracking or analytics included
