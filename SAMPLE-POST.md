# My first post

This whole post is just a **markdown file** on GitHub. Push it to the
`posts/` folder in your `blog` repo and it appears on the site automatically —
no code, no redeploy.

## You can write anything

- Bullet points
- **Bold** and *italic*
- `inline code`
- Links: [my GitHub](https://github.com/abdulmanan69)

### How to publish
1. Add a new `.md` file to the `posts/` folder in your `portfolio` repo on GitHub.
2. Name it (e.g. `learning-react.md`).
3. Change the front-matter at the top (title, date, excerpt, cover, tags).
4. Write. Commit. It appears on the site automatically.
